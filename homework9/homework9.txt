Задание:
Необходимо реализовать docker-compose, который будет разворачивать следующие компоненты
1. PostgreSQL (port 5432)
2. Grafana (port 3000)
3. Prometheus (port 9090)
4. Node exporter (port 9100)
5. Postgre Exporter (port 9187)

Примечания:
1. чтобы примонтировать конфиг prometheus.yml к prometheus container можно использовать след команду:

volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml:ro

2. для node_exporter:
volumes:
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
      - /:/rootfs:ro
command:
      - '--path.procfs=/host/proc'
      - '--path.rootfs=/rootfs'
      - '--path.sysfs=/host/sys'
      - '--collector.filesystem.mount-points-exclude=^/(sys|proc|dev|host|etc)($$|/)'

3. Для exporter также требуются линки на контейнер postgre and prometheus:
links:
      - postgres
      - prometheus

После разворачивания необходимо настроить мониторинг и получить аппаратные метрики (node exporter) и
postgre exporter

На проверку прислать готовый docker-compose.yaml + скрины с выше описанными метриками
